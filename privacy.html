어디갈래 개인정보 처리방침

시행일: 2026년 11월 1일

1. 수집하는 개인정보

어디갈래는 회원가입이 없으며 이름, 연락처, 위치정보 등 개인정보를 수집하지 않습니다.

2. 기기에 저장되는 정보

담아 둔 코스, 다녀온 도시 도장, 마지막으로 본 탭 같은 화면 설정은 사용자의 기기 브라우저 저장소에만 보관합니다. 이 정보는 기기 밖으로 전송되지 않으며 앱 데이터를 지우면 함께 삭제됩니다.

3. 방문 통계

몇 명이 앱을 쓰는지 알기 위해, 앱을 열 때 날짜별 숫자 하나만 무료 카운터 서비스(Abacus, abacus.jasoncameron.dev)에 1씩 올립니다. 같은 기기가 하루에 여러 번 세지지 않도록 '오늘 이미 셌는지' 표시만 기기 저장소에 남깁니다. 쿠키, 기기 식별자, 위치, 이름 등 개인을 알아볼 수 있는 정보는 보내지 않습니다.

4. 영상 코스와 제보

'영상 그대로 여행'에 입력한 유튜브 링크는 장소를 찾기 위해 어디갈래 도우미 서버(Cloudflare Workers)로 보내지고, 결과를 돌려준 뒤 따로 보관하지 않습니다. '숨은 핫플 제보'에 적은 장소 이름·도시·이유·링크는 운영자에게 메시지로 전달되며, 이름이나 연락처는 받지 않습니다.

5. 외부 서비스 연결

영상·지도·인스타그램 링크를 누르면 YouTube, 카카오맵, Instagram 등 외부 서비스로 이동합니다. 이동한 뒤의 정보 처리는 각 서비스의 방침을 따릅니다. 앱에 표시되는 영상 정보는 YouTube API 서비스를 통해 가져오며, YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

6. 정보 출처

관광지·음식점 정보는 한국관광공사 TourAPI(공공데이터포털) 데이터를, 인기 순위는 한국관광공사 지자체 중심 관광지 정보를 이용합니다. '요즘 뜨는 곳'은 YouTube API 서비스로 받은 공개 영상의 제목·설명·조회수로 계산하며, 일부 장소는 카카오맵 장소 페이지로 연결됩니다.
